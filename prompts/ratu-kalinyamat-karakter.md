# Desain Karakter — "Ratu Kalinyamat"

Total: **17 lembar karakter** + 1 gambar transformasi + 1 gambar lineup. Rasio yang disarankan 3:2 atau 16:9.

Semua karakter memakai gaya stickman yang sama dengan lembar referensi kamu (kepala bulat putih, tubuh garis hitam tipis, garis tebal doodle); yang berbeda hanya pakaian dan properti khas abad ke-16.

## Cara pakai di Google Flow

1. Upload lembar karakter stickman kamu sebagai **Ingredient / reference image** (untuk gaya gambar).
2. Generate setiap lembar karakter di bawah. Pilih hasil terbaik untuk tiap karakter.
3. Simpan hasil terpilih sebagai **Ingredient** dengan nama karakternya (mis. `Ratu Kalinyamat`). Lembar-lembar inilah yang nanti dipakai sebagai referensi saat membuat gambar per timestamp.

### Instruksi untuk agent Flow

```
Generate one character reference sheet for EACH prompt below (tagged [ratu], [trenggana], ...), plus the [transformasi] and [lineup] images. Use the attached stickman sheet only as the ART STYLE reference: round white heads, thin black stick limbs, thick clean black outlines, flat muted colors. Follow each prompt's outfit description exactly. Name each image with its tag. Do not add any text or labels.
```
