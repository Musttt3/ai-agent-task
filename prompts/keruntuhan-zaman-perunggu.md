# Prompt Gambar Stickman — "Keruntuhan Zaman Perunggu"

Total: **107 prompt** (1 prompt per timestamp). Rasio 16:9. Prompt dalam bahasa Inggris agar hasil model gambar lebih akurat.

Konsep: karakter stickman purba dari lembar referensi menjadi **pemandu/saksi** yang hadir di setiap adegan (desainnya tetap sama). Tokoh zaman perunggu (firaun, raja Het, pedagang Ugarit, prajurit Mykenai, Bangsa Laut) digambar sebagai stickman lain dengan gaya yang sama dan pakaian khas zamannya.

## Cara pakai di Google Flow

1. Upload lembar karakter stickman (tampak depan, samping, belakang + ekspresi) sebagai **Ingredient / reference image**.
2. Tempel instruksi agent di bawah, lalu tempel isi file `keruntuhan-zaman-perunggu.txt`.
3. Nama file hasil = timestamp, supaya mudah disusun di editor video.

### Instruksi untuk agent Flow

```
Generate one 16:9 image for EACH prompt below, in order. Use the attached stickman caveman character sheet as the reference for the main character in every image and keep his design identical (round white head, messy shaggy dark-brown hair, thin black stick limbs, ragged brown fur tunic with white fur collar and rope belt, stone-tipped wooden spear). Use the expressions from the sheet when a prompt asks for worried, happy, skeptical, surprised, scared or angry. Draw all other people as stickmen in the same style. Keep the same hand-drawn doodle art style across all images. Name each image with its timestamp (e.g. 0-00, 0-07). Do not add any text or captions.
```
